# Accel Jellybean

Android app that reads and visualizes accelerometer sensor data in real time.

## Features
- Real-time accelerometer data capture
- X, Y, Z axis visualization
- Data logging

## Requirements
- Android Studio
- Android SDK 21+
- Physical device recommended (for sensor access)

## Installation
```bash
git clone git@github.com:EdisonArteagaLopez/accel_jellybean.git
```
Open in Android Studio → Build → Run
